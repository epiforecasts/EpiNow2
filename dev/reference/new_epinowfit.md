# Construct a fitted model object

Combines the components of a fitted model into a list with class
`c(class, "epinowfit", "list")`.

## Usage

``` r
new_epinowfit(..., class)
```

## Arguments

- ...:

  Named components of the object, in the order they should appear.

- class:

  Character, the model-specific class.

## Value

A list of class `c(class, "epinowfit", "list")`.
