Detailed Description

template<typename Vec>
struct epinow2::internal::renewal_state< Vec >

Forward values kept for the reverse pass.

Each member has one entry per time step, except I, which also holds the seeds. The entries of flag are bit sets, with 1 for depletion, 2 for S = pop - C (not the floor) and 4 for fmax(0, 1 - e) passing 1 - e through.

Template Parameters
VecVector type, either Eigen::VectorXd or an arena vector.
